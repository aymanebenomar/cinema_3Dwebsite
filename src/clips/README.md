# Your clips

Drop video files here (`.mp4`, `.webm`, `.mov`, `.m4v`) and they join the programme automatically,
ahead of the free films. Each plays for 10 seconds, starting at a random scene, then crossfades to the next.

The title on screen comes from the file name:

| File | Shows as |
| --- | --- |
| `the-batman.mp4` | The Batman |
| `la-la-land.mp4` | La La Land |
| `spider-man-no-way-home.mp4` | Spider Man No Way Home |

Files play in alphabetical order, so prefix them (`1-the-batman.mp4`, `2-la-la-land.mp4`) to choose the order,
or give a clip a fixed title or start time by listing it in `src/clips.js`.

Only use footage you have the rights to show, especially if the site goes public.
